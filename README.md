# CablePlan — кабельный план

Приложение для раскладки кабельных трасс по планам здания и расчёта кабельного журнала.

Загрузите PDF-план, откалибруйте масштаб по двум точкам, расставьте оборудование (камеры, шкафы), начертите трассы (лоток, гофра, стояк) и привяжите к ним кабели. Программа сама проложит маршрут между устройствами, посчитает длины с учётом высот прокладки и запасов и сформирует кабельный журнал и ведомости.

## Возможности

**Работа с планами**
- Загрузка PDF-плана: несколько страниц и этажей, калибровка масштаба «по двум точкам».
- Приближение двумя пальцами (на сенсорных экранах), панорамирование, сетка и привязка.

**Оборудование**
- Камеры, шкафы и любые другие типы с уникальным обозначением и именем.
- Высота от пола, дополнительные свойства, копирование и перетаскивание.

**Трассы (кабеленесущие системы)**
- Цепочки прямых сегментов: ортогональные или пространственные, с высотой прокладки.
- Межэтажные стояки с учётом отметок пола.

**Кабели**
- От оборудования до оборудования, с количеством, запасами в % и метрах, концевыми запасами.
- **Автопрокладка маршрута:** выберите «От» и «До» — программа сама найдёт путь по начерченным трассам.

**Расчёт и документы**
- Точный расчёт: геометрия → запас трасс → запас кабеля → концы → итог одного кабеля.
- Кабельный журнал и ведомости (оборудование, кабельная продукция, инфраструктура, предупреждения).
- Неполные данные не подменяются нулём — итог помечается как неполный.

**Хранение и экспорт**
- Локальное хранение: SQLite-файл в `data/` и исходные PDF там же (без внешних сервисов).
- Экспорт в CSV / XLSX / PDF, резервная копия JSON с исходными PDF.
- Восстановление из JSON-копии, удаление сохранённых проектов.

## Запуск локально

Требуется **Node.js 22.5+** (используется встроенный `node:sqlite`). Проверено на Node 24.

```bash
npm install
npm run build        # TypeScript + Vite, сборка в dist/
npm start            # API + раздача сайта на http://0.0.0.0:3001
```

Откройте http://localhost:3001

Режим разработки (Vite HMR на :5173 + API на :3001):

```bash
npm run dev
```

## Быстрый старт

1. Нажмите «Учебный проект» — откроется синтетическая схема с полным расчётом (для знакомства с интерфейсом).
2. Или загрузите свой PDF: выберите этаж → «Загрузить PDF» → выберите страницу → инструмент «Масштаб», укажите две точки и введите расстояние в метрах.
3. Инструмент «Оборудование» — кликом расставьте камеры и шкафы, задайте высоту в свойствах.
4. Инструмент «Трасса» — кликами начертите ломаную (Enter — завершить), задайте тип и высоту.
5. Инструмент «Кабель» — выберите «От» и «До»; маршрут построится сам. Задайте марку, запасы и количество.
6. Вкладки «Кабельный журнал» и «Ведомости» — итоговые длины и спецификация.

> В расчёт попадают только полные данные: неизвестный масштаб, отметка или высота помечают итог как неполный и не подставляют нулевые длины.
